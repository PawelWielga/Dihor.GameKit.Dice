Appearance

Advanced appearance & assets Custom font, global texture and per-face overrides
Custom font URL optional

D6 keeps dots by default. Switch it to Numbers to verify the same font and the orientation marker under 6. D10/D20 also make 9/19 easy to inspect.

Global texture URL optional
Per-face texture overrides

A successfully loaded face texture replaces the generated marking only on that physical face. The demo exposes the first six faces; the library API accepts every face of the selected die.

Table Surface color and optional texture
03

Table

Configure the visible table material without changing dice physics.

Table texture URL optional

The texture affects only the rendered table. The cannon-es collision plane and logical dice result stay unchanged.

Camera Orbit, tilt and distance
04

Camera

X orbits around the table, Y tilts away from top-down, Z controls distance.

Set X = 0° and Y = 0° for an exact vertical top-down view. At Y = 0°, changing X does not change the view because the camera is directly above the table center.

Lighting Scene mood, key light and presets
05

Lighting

Change the scene mood without affecting dice physics or the logical result.

Neutral matches the previous DiceKit defaults. Presets only change rendering. Directional and point lights can also be mixed through the public API.
